# Agence Reputation Manager

Plateforme de veille e-réputation pour agences de communication.
Chaque agence dispose de sa propre plateforme (nom, logo, couleurs) et y gère ses clients.

- `index.html` : la plateforme (page unique, hébergée sur GitHub Pages).
- `img/` : éléments d'image de marque.
- `supabase/functions/gerer-utilisateur/` : création et gestion des comptes.
